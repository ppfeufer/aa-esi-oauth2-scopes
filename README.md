# AA ESI OAuth2 Scopes

### ESI OAuth2 Scopes and what each scope unlocks

Alliance Auth App to show which ESI OAuth2 scopes unlock which endpoints.

This is tailored for developers who want to know what each scope unlocks in ESI, and
for those who want to know what scopes they need to request from their users. This
is not meant to be installed in production, but rather to be used as a reference
for developers.

Inspired by Steve Ronuken's [Fuzzworks version](https://www.fuzzwork.co.uk/scopes/).
